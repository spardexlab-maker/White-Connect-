- المساعد الذكي صار محادثة: احجي بصوتك (زر المايك) أو اكتب، والجواب ينكتب قدامك مباشرة، وتكدر تكمل الحجي وياه.
- زر «استمع» يقرالك جواب المساعد بصوت.
- بالآخر يقترحلك التخصص والتحاليل، وزر يعرضلك أقرب الأطباء أو المختبرات.
- تاريخ الميلاد صار بالاختيار (يوم، شهر، سنة) بدل الكتابة.
- هذي النسخة تحتاج تنصيب جديد مرة وحدة (لأن المايكروفون صلاحية جديدة)، وبعدها التحديثات ترجع تلقائية.
