# إدخال البيانات بالجملة

1. عبّي `abyad-import-template.xlsx`: ورقة «الجهات» و«الأطباء» و«الموظفون» (شرح كل خانة بورقة «اقرأني»).
2. فحص الملف وتحويله:
   `python3 -I scripts/import_directory.py filled.xlsx --admin-email <بريد مدير المنصة> --out import.sql`
   يطلع تقرير بالعربي بأي خطأ، وما يكتب شي إلا إذا الملف كله سليم.
3. تشغيل `import.sql` على قاعدة البيانات (معاملة وحدة: يا ينضاف كله، يا ما ينضاف شي). يصير عن طريق دوال الإدارة
   نفسها، ويتسجل بسجل التدقيق باسم المدير (`directory.imported`). تشغيله مرتين ما يكرر شي.
4. الحسابات تنخلق بدون كلمة مرور: كل شخص يدخل بـ Google على نفس البريد، أو «نسيت كلمة المرور».

إعادة بناء القالب: `python3 scripts/make_import_template.py`
