# مراجعة الواجهة قبل التطوير البصري (v2)

## ما يجب المحافظة عليه (لا يُمس منطقه)
* كل المسارات في `apps/web/src/App.tsx` وحماية الأدوار (`guards.tsx`) ومبدل مساحة العمل.
* كل استدعاءات RPC والحقول ومفاتيح idempotency ومعالجة `slot_unavailable` وأخطاء `errorMessage`.
* الحجز للمريض بأربع مراحل مع حفظ المسودة عند الدخول، وحالة «بانتظار التأكيد» منفصلة عن «مؤكد».
* الاستقبال: حجز سريع بالاسم فقط (اختصار N)، قائمة الانتظار، التأكيد/الرفض/الحضور/المغادرة/الغياب، البحث وQR، الفواتير، إشعار التأخير، تحديث Realtime.
* الطبيب: الجلسة بخمسة تبويبات، الحفظ التلقائي والقفل بعد الاعتماد، الحساسية، الوصفة (مسودة/اعتماد/طباعة/إرسال لصيدلية مختارة صراحةً)، طلب التحاليل، المهام.
* الطباعة (`print-area`) وصفحة التحقق، وسمات الوصول (أدوار ARIA، focus trap، التبويب بالأسهم RTL).
* مطابقة الألوان لاختبار التباين في `packages/shared/src/tokens.ts`.

## المشكلات البصرية والتجربة
| # | المشكلة | الأثر |
|---|---|---|
| 1 | رئيسية المريض صندوق نموذج أبيض بلا هوية؛ لا تسلسل بصري بين البحث والتخصصات والنتائج | شكل «نموذج إداري» لا منتج |
| 2 | بطاقات الأطباء متطابقة الوزن، زر داكن كبير مكرر في كل بطاقة يطغى على المعلومات | ازدحام وتكرار |
| 3 | الشريط الجانبي الأزرق الداكن الفارغ + شريط علوي رمادي = قالب Dashboard عام؛ اسم مساحة العمل صغير | لا شخصية؛ سياق العمل غير بارز |
| 4 | لوحة الاستقبال: كل الأفعال بنفس الوزن (بطاقة/رسوم/إلغاء/حضور) في كل صف؛ لا فصل بصري بين محجوز/حضر/ينتظر/داخل الجلسة | بطء القراءة وأخطاء ضغط |
| 5 | جلسة الطبيب: عمود طويل من الحقول بلا تجميع؛ لا قائمة مرضى اليوم بجانب الجلسة | تنقل كثير بين الصفحات |
| 6 | لا انتقالات بين الصفحات، تغيّر الحالة يحدث فجأة، النوافذ تظهر دون حركة دخول متناسقة | إحساس جامد |
| 7 | حواف وظلال وأحجام غير موحدة؛ لا مقياس ارتفاع (elevation) | عدم تناسق |
| 8 | منتقي الأيام والأوقات وظيفي لكن بلا تجميع (صباحاً/مساءً) ولا إبراز للوقت المختار | قرار أبطأ |

## القرارات
* **لا مكتبة حركة:** كل الحركات CSS (transform/opacity) مع رموز مدة 150–250ms واحترام `prefers-reduced-motion`. React Router + مفاتيح المسار تكفي لانتقال الصفحات؛ لا حاجة لـFramer Motion (≈50KB).
* **نظام التصميم v2** يبقي أسماء الأصناف الحالية (فتتحسن كل الشاشات تلقائياً) ويضيف رموز الارتفاع والحركة ومكونات جديدة.
* **Light Mode فقط** في هذه المرحلة؛ الوضع الليلي لا يُفعّل إلا بعد اكتماله واختباره على كل الشاشات.
