✔ = تم التحقق في هذا التسليم، ◐ = جزئي، ☐ = لم يُتحقق بعد.

## RTL
- ✔ `dir="rtl" lang="ar"` على المستند؛ خصائص CSS منطقية فقط.
- ✔ الهواتف والمعرفات وأرقام الحجز والبريد معزولة LTR (`<bdi dir="ltr">`، حقول `dir=ltr`).
- ✔ الشريط الجانبي يميناً؛ أسهم «السابق/التالي» معكوسة يدوياً؛ الأيقونات غير الاتجاهية غير معكوسة.
- ✔ أسماء عربية طويلة: `truncate` في الصفوف الضيقة مع بقاء الاسم كاملاً في التفاصيل.
- ◐ نصوص مختلطة عربية/إنجليزية في أسماء المنتجات الدوائية (المرحلة 3).

## التجاوب
- ✔ 360/390/768/1024/1440: لا تمرير أفقي للصفحة (فحص آلي في `scripts/screenshots.mjs`).
- ✔ الجداول داخل منطقة تمرير معنونة (`role="region"` + `aria-label` + `tabIndex=0`).
- ✔ اللوحات الجانبية تصبح ملء الشاشة على الهاتف؛ التنقل السفلي للمريض يصبح علوياً ≥1024px.

## الإتاحة
- ✔ تباين AA لكل أزواج الألوان (اختبار وحدة).
- ✔ تسميات ثابتة لكل الحقول، أخطاء بجانب الحقل مع `role="alert"` و`aria-describedby`.
- ✔ تركيز مرئي (`:focus-visible`)، رابط «تخطَّ إلى المحتوى»، focus trap وEsc في الحوارات.
- ✔ التبويبات: `role=tablist/tab/tabpanel` وأسهم الكيبورد.
- ✔ الحالات نص + أيقونة؛ لا اعتماد على اللون وحده.
- ✔ مناطق لمس 44px للأفعال الأساسية.
- ✔ `prefers-reduced-motion` يلغي الحركة.
- ✔ الحجز السريع بالكيبورد: `N` يفتح اللوحة، الاسم يأخذ التركيز، Enter يرسل.
- ☐ اختبار قارئ شاشة فعلي (NVDA/VoiceOver) — لم يُنفذ بعد.

## الحالات
- ✔ كل شاشة بيانات لها loading (skeleton) / empty (يشرح الخطوة التالية) / error (مع إعادة المحاولة) / permission-denied.
- ✔ لا نجاح متفائل: «جارٍ الحفظ…» وتعطيل الإرسال المكرر + idempotency خادمي.
- ✔ لافتة انقطاع الشبكة، وتعطيل الإرسال للعمليات الخادمية أثناء الانقطاع؛ المدخلات لا تُمسح عند الخطأ.
- ✔ لا أزرار أو تقارير أو إشعارات وهمية: الوحدات غير المنفذة تقول ذلك صراحة.
